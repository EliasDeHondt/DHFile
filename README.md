## 🖖Introduction

DHFile is a modern tabbed file explorer for Windows by Group DH, in the house style of DHMail and DHTerminal. It does what Windows Explorer does — browse, copy, move, rename, delete, search, preview — with tabs, your own pinned folders, a PIN lock and full control over how it looks. If you want, DHFile also takes over from Explorer: folders, drives and Win + E then open in DHFile.
